CyberSakhi — Cyber Safety Companion
CyberSakhi is a Python-based cybersecurity project that helps users identify potential phishing attempts, recognize suspicious messages, and respond to cyber incidents.

✨ Key Features
Message Analysis: Detects urgency, threats, credential requests, suspicious links, and reward-related language.
URL Analysis: Checks URLs for common warning signs.
Risk Assessment: Assigns a risk score and categorizes potential threats as Low, Medium, or High.
Voice Assistant: Reads risk assessments and recommended actions aloud.
Emergency Mode: Provides safety guidance for suspicious links, compromised credentials, OTP sharing, financial fraud, and suspicious downloads.
🛠️ Tech Stack
Python
Streamlit
HTML, CSS
🎯 Objective
To promote cybersecurity awareness by helping users recognize potential threats, understand risks, and take safer actions online.

⚠️ Disclaimer
CyberSakhi uses rule-based detection. Its results are indicators, not proof that a message or URL is safe or malicious.
